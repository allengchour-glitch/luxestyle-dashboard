Facebook Page-Token Helfer

Holt ein nie ablaufendes Page-Token für „LuxeStyle CH“. Läuft komplett lokal in deinem Browser — direkt zu Facebook, nichts geht an Dritte.
Vorher im Graph API Explorer: App „LuxeStyle Social“ wählen → Generate Access Token mit den Scopes pages_show_list, pages_read_engagement, pages_manage_posts, pages_manage_engagement, instagram_basic, instagram_content_publish, instagram_manage_comments → das (kurzlebige) User-Token kopieren und unten einfügen.

Bleibt in deinem Browser. Wird nur direkt an facebook.com gesendet, nie an Dritte.
