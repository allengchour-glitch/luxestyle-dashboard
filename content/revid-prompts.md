# 🎬 Revid.ai — Generierungs-Prompts pro Produkt (LuxeStyle)

Für die 90 Reels aus `content/reels-schedule-90.csv`. Jedes Produkt hat einen **Master-Script-Prompt**; die 3 Tages-Formate variieren nur den Hook (erste 2 Sek.).

## ⚙️ Globale Revid-Settings (für alle)
- **Format:** 9:16 (Reels/Shorts/TikTok) · ~15–25 Sek.
- **Captions:** AN (auto, bold, mittig-unten) · **Musik:** trendy/upbeat, dezent
- **Visuals:** „Stock footage + product B-roll" (oder eigene Produktbilder hochladen für echte Optik)
- **Voiceover:** EN = energetic female · DE = natürliche weibliche Stimme
- **Branding:** Endcard „LuxeStyle · luxestyle.com.co" · Code-Overlay (WELCOME10 / USA15)
- **CTA-Overlay letzte 3 Sek.:** „-10% · Code WELCOME10 · Link in Bio"

## 🔌 Revid + Make.com (Automatik)
Revid „Create Video" (API/Make-Modul) → Feld **script** = Prompt unten, **aspect_ratio** = 9:16, **captions** = true.
Mapping aus CSV: `caption`/`hook`/`product` → Script, `video_file` = Output-Dateiname → Drive → Posting-Szenario.
